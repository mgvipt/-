# Калькулятор декоратора — приложение для iPhone

Мобильное приложение на **React Native (Expo)** для быстрого расчёта сметы
оформления: материалы, наценка, работа, доставка, скидка и итог «к оплате».

## Что умеет

- Список позиций (материал/услуга): наименование, количество, цена за единицу
- Наценка на материалы (%)
- Стоимость работы / монтажа (₽)
- Доставка (₽)
- Скидка клиенту (%)
- Итоговая сумма к оплате
- Кнопка «Поделиться сметой» — отправляет текст сметы (WhatsApp, Telegram, почта…)
- Все данные сохраняются на устройстве (AsyncStorage)

## Как запустить на iPhone (без Mac)

1. Установите на iPhone бесплатное приложение **Expo Go** из App Store.
2. На компьютере (в этой папке) выполните:

   ```bash
   npm install
   npx expo start
   ```

3. В терминале появится **QR-код**. Откройте на iPhone камеру (или Expo Go) и
   отсканируйте его — приложение запустится на телефоне.

   > iPhone и компьютер должны быть в одной Wi-Fi-сети. Если сеть не пускает,
   > запустите туннель: `npx expo start --tunnel`.

## Сборка отдельного приложения (.ipa, без Expo Go)

Чтобы получить самостоятельное приложение и поставить его на iPhone /
опубликовать в App Store, используйте облачную сборку EAS (Mac не нужен):

```bash
npm install -g eas-cli
eas login
eas build --platform ios
```

Для установки на личный iPhone понадобится аккаунт Apple Developer.

## Структура

- `App.js` — весь экран и логика расчёта
- `app.json` — конфигурация Expo (имя, иконка, сплэш)
- `assets/` — иконка и заставка
