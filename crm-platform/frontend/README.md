# GMIdeas CRM — Frontend (React + TypeScript + Vite)

Боевой интерфейс поверх Django API: вход по токену, канбан с перетаскиванием
карточек (меняет стадию через API), карточка сделки, матрица ролей, меню по правам,
тема оформления (сохраняется в профиле сотрудника).

## Запуск (dev) — нужны ДВА терминала

**Терминал 1 — бэкенд:**
```bash
cd crm-platform/backend
python manage.py migrate
python manage.py seed_demo
python manage.py runserver        # http://localhost:8000
```

**Терминал 2 — фронтенд:**
```bash
cd crm-platform/frontend
npm install
npm run dev                       # http://localhost:5173
```
Открыть **http://localhost:5173**. Запросы `/api/*` Vite сам проксирует на Django.

## Что уже работает
- 🔐 Вход/выход по токену.
- 📋 Канбан лидов и 🤝 сделок — данные из API, **drag&drop** меняет стадию (сохраняется).
- 🔀 Переключение воронок (только доступные роли).
- 🃏 Карточка сделки с прогрессом по стадиям.
- 🛡️ Матрица ролей — галочки выдают права (сохраняется сразу).
- 🎨 Тема (фон/акцент) — в профиле пользователя.
- Меню прячет разделы, на которые нет прав (Финансы/Склад/Телефония/Права).
