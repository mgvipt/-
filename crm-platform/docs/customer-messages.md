# Повідомлення клієнту — живе дзеркало

Рішення Олега 21.09.2026: менеджерам потрібні чинні тексти, умови й рух угоди без технічних подробиць. Шлях: чат → Бібліотека → Швидкі відповіді → «Оплата, доставка, майстер-класи · автоматичні повідомлення».

## Єдині джерела
- `apps/crm/customer_messages.py`: builders онлайн-посилань, даних доставки, строку, подяки/чека, ТТН та допродажу. Відправка у `crm/views.py` викликає ті самі builders.
- Реквізити: чинний `crm.views.requisites_text`, без копії реквізитів.
- Статуси НП: чинний `np_status_sync._msg`, той самий builder для відправки й довідника.
- Майстер-класи: live QuickReply у категорії «Майстер-класи»; активність автоматичного PATTERA перевіряє GlobalRule + active reply + URL, як відправник.
- Відгуки: live ReviewSettings, тексти/строки/стан перемикачів. На момент релізу send_enabled=False, test_mode=True; нічого не вмикали.
- Персоналізована подяка: показано базові варіанти, а не обіцянку точного фінального тексту; точний результат у чаті.

GET `/api/inbox/media-library/?view=automations` read-only, звичайна авторизація бібліотеки, Cache-Control:no-store. Не створює QuickReply/ReviewSettings, не надсилає повідомлень. UI читає при відкритті, фокусі та кожні 60с; помилку оновлення показує явно. Перегляд не має кнопки відправки, Enter не вставляє текст у чат. Зміна джерела з'являється без синхронізації копій; кодові шаблони — після звичайного deploy автоматизації.

## Важливі відмінності
Посилання ≠ підтвердження платежу; бронювання має окрему стадію. Дані НП та строк надсилає кнопка оплати, окремий send_requisites помічника — тільки реквізити/IBAN/призначення. Допродаж інструментів запускається після успішної онлайн-оплати. Підготовка, «В дорозі» та «Отримано» не мають окремого повідомлення у НП-ланцюжку. Відгуки — окрема умовна автоматика, стан показано наживо.

Єдина зміна клієнтського формулювання: при створенні ТТН тепер «Для вашого замовлення створено ТТН Нової Пошти!», без неправдивого «відправлено». Фактична відправка — окремий статус НП. Формування післяплати збережено. Форма np_save зберігає прапорець одноразової відправки майстер-класу, як решту прапорців повідомлень.
