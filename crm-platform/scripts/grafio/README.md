# Grafio: проверка публичных цен

Подготовлено 17.09.2026. Production не изменён. Только стандартная библиотека Python 3.

## Запуск

```sh
python3 sync.py --inventory /path/to/catalog.json --output /path/to/snapshot.json
python3 -m unittest discover -s /path/to/grafio-sync -p 'test_sync.py'
```

В качестве следующего inventory подходит сам snapshot.json: стабильные sourceID и slug сохраняются. Новые URL не обнаруживаются и товары автоматически не добавляются. 223 исходных ID обязательны. Обнаружение новых позиций — отдельная задача с ручной проверкой.

Парсер читает только публичный HTML карточек, включая опубликованные SSR-данные __NUXT_DATA__, и robots.txt. Не вызывает /api/ и не загружает картинки; ссылки api.grafio-decor.com.ua/wp-content/uploads/... — исходные ссылки изображений, а не запросы private API. Между началами запросов минимум1.1сек. 403/429 немедленно останавливают crawl.

## Контракт

`complete:true` означает223 успешных карточки со стабильными ID; не означает отсутствие спорных единиц. `products[].sourceID` — числовой databaseId поставщика. `price` — десятичная строка UAH либо null; никогда не0 из-за ошибки. Источник цены — единственный видимый ценник в основном блоке покупки публичной карточки. Внутренний SSR product.price сохраняется отдельно как sourcePriceSSR; расхождение фиксируется в sourceDiscrepancies и не блокирует достоверную видимую цену. Неоднозначный/отсутствующий видимый блок при наличии SSR-цены блокирует автоматическое применение. regularPrice/salePrice сохраняются отдельно. `unit` сохраняет исходную надпись без конверсии; unitVisible, unitCategoryEvidence и unitDescriptionEvidence сохраняют доказательства. `reviewIssues` блокируют автоматическое применение записи. `status=price_on_request` означает действительно отсутствующую цену, не ошибку запроса.

Один fetch/parse/ID failure = выход с ошибкой, старый snapshot остаётся нетронутым. В stdout выводятся счётчики и ошибки без описаний товаров и клиентских данных. Полная новая версия записывается через atomic rename. При пропаже цены в полной карточке price=null: импортёр должен отключить публичную покупку/перевести в «уточнить цену», сохранив старую цену отдельно в истории, а не отображать старую как актуальную и не записывать0.

Описание, атрибуты, ассортимент, изображения и наличие принадлежат источнику. descriptionHTML/description — исходные данные, НЕ готовый текст дилера. Нельзя автоматически публиковать от Wallcov «мы производители». Для безопасного краткого описания использовать название, исходные размеры и согласованные факты. Supplier stock не является остатком Wallcov. Не размножать подтовары набора как новые223позиции: subproducts сохраняется отдельно.

## Регулярная проверка

По уточнённому решению root подготовлены systemd service+timer:00:00,06:00,12:00,18:00 Europe/Kyiv, flock допускает один процесс. Обновление не мгновенное. Полный crawl занимает несколько минут.

Интегратор: сначала DRY_RUN и отчёт отличий; затем1–2товара и проверка; далее223по согласованным правилам. Upsert только по supplier=Grafio+sourceID. Не сопоставлять legacy по одному артикулу при вариантах/разной единице. Не создавать новый товар при каждом запуске. Импортёр обязан читать только complete=true, не применять review_required, проверять currencyUAH, хранить old/new/sourceURL/checkedAt, и не считать одинаковую цену при разных единицах совпадением. При прерывании/ошибке оставить прежние цены и уведомить ответственного; при устаревшей сверке показывать внутренний статус, не обещать актуальность.

Установка service/timer — только root после проверки этого пакета. Файлы — проверяемая заготовка, не работающая production-синхронизация.
