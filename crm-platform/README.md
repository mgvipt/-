# GMIdeas CRM

Собственная CRM-платформа (замена Bitrix24): омниканальные чаты, телефония с записью,
склад, финансы и роли — self-hosted, на своём сервере.

## Интерактивное превью дизайна
Открой **`preview.html`** в браузере (двойной клик или перетащить в окно браузера).

Экраны (переключаются в левом меню):
- **Лиды** — канбан как в Bitrix
- **Сделки** — канбан с выбором воронки (21 Основний продукт / 22 Тестовий набір)
- **Карточка сделки** — клиент, оплата, таймлайн, плеер записи звонка, бизнес-процессы (клик по любой карточке)
- **Чаты · Открытые линии** — единый inbox всех мессенджеров + карточка клиента
- **Телефония** — журнал звонков с записями
- **Товары · Склад** — остатки, накладные, инвентаризация
- **Финансы** — cashflow, кассы (виден только по правам)
- **Аналитика** — воронка продаж
- **Сотрудники и права** — матрица ролей (динамическая)
- **Настройки** — все интеграции/каналы

Сверху справа — кнопка **🎨 Тема**: смена фона рабочего стола и акцентного цвета
(в реальной системе сохраняется в профиле каждого сотрудника).

## Боевая версия (рабочее приложение)
- **`backend/`** — Django + DRF: CRM-ядро (лиды, сделки, воронки, контакты, оплаты) + RBAC. См. `backend/README.md`.
- **`frontend/`** — React + Vite: живой интерфейс поверх API (вход, канбан с drag&drop, карточка сделки, роли). См. `frontend/README.md`.

Быстрый старт: подними бэкенд (`backend/README.md`), затем фронт (`frontend/README.md`), открой http://localhost:5173.

## Документы

Боевые модули разрабатываются поэтапно — см. ARCHITECTURE.md.
