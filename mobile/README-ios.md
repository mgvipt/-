# Публикация «Цикл вдвоём» в App Store (iOS)

Этот каталог — обёртка на [Capacitor](https://capacitorjs.com/), которая упаковывает
веб-приложение из `../app` в нативное iOS-приложение для публикации в App Store.

> **Важно.** Сборку и публикацию iOS-приложения **невозможно** выполнить на Linux или в CI.
> Это делается **только на компьютере Mac** с использованием Xcode и учётной записи
> Apple Developer владельца приложения. Шаги ниже выполняет человек с Mac.

## Предварительные требования

- **macOS** с установленным **Xcode** (из Mac App Store).
- Аккаунт **Apple Developer** — 99 долларов США в год (https://developer.apple.com/programs/).
- **CocoaPods**: `sudo gem install cocoapods` (или `brew install cocoapods`).
- **Node.js 18+** и npm.

## Шаги сборки

Выполняйте в каталоге `mobile/`:

```bash
cd mobile
npm install          # установить Capacitor
./copy-web.sh        # скопировать веб-приложение из ../app в ./www
npx cap add ios      # создать нативный iOS-проект (только на Mac!)
npx cap sync         # синхронизировать веб-ресурсы и плагины
npx cap open ios     # открыть проект в Xcode
```

При каждом обновлении веб-приложения повторяйте:

```bash
./copy-web.sh && npx cap sync
```

## Настройка в Xcode

1. Выберите проект **App** → вкладка **Signing & Capabilities**.
2. В поле **Team** выберите свою команду Apple Developer (нужен вход в Apple ID).
3. Убедитесь, что **Bundle Identifier** = `app.cyclevdvoem`
   (совпадает с `appId` в `capacitor.config.json`).
4. Задайте **иконки приложения**: `App/App/Assets.xcassets/AppIcon.appiconset`
   (можно взять `../app/icon-512.png` и сгенерировать нужные размеры,
   например через https://appicon.co/).
5. Проверьте отображаемое имя приложения (Display Name) — «Цикл вдвоём».

## Публикация

1. В Xcode выберите устройство сборки **Any iOS Device (arm64)**.
2. Меню **Product → Archive**. Дождитесь окончания архивирования.
3. В окне **Organizer** нажмите **Distribute App → App Store Connect → Upload**.
4. Зайдите в **App Store Connect** (https://appstoreconnect.apple.com):
   создайте карточку приложения, заполните описание, скриншоты, политику
   конфиденциальности, возрастной рейтинг.

## TestFlight (тест до публикации)

- После загрузки сборки она появится в **TestFlight**.
- Добавьте тестировщиков (клиентов) по e-mail — они установят приложение
  через приложение **TestFlight** на iPhone **до** публичного релиза.
- Это удобный способ дать клиентам попробовать приложение сразу, пока идёт
  проверка Apple.

## Проверка Apple

- После отправки на ревью проверка Apple обычно занимает **1–3 дня**.
- Могут запросить доработки (приватность, описание функций и т. п.).
- После одобрения приложение появится в App Store.
